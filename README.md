An entry for [Funniest Forecast for a City That Isn't](https://make.fun/bounty/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf) on make.fun.

A one-line weather forecast for Nowhere, a city that does not exist:
yesterday is coming back with total certainty, regrets are scattered
like showers, the high never quite arrives, and the void itself needs
an umbrella. Flat bulletin phrasing, then the weather breaks.

## The entry (116 characters)

> Today in Nowhere: 100% chance of yesterday, scattered regrets, and a high of almost. Bring an umbrella for the void.

## How to run

`main.py` (Python 3, standard library only) writes the line to
`entry.txt` in the output directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program is deterministic: no time, no randomness, no network. It
writes the exact same bytes on every run.
